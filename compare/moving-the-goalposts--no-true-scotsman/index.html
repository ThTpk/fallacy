ได้หลักฐานตามที่ขอแล้ว จึงขอหลักฐานชนิดใหม่แทน โดยไม่รับว่าของเดิมผ่าน

ตรรกวิบัติไม่ใช่พวกเราตัวจริง
No True Scotsman

เจอตัวอย่างที่ขัดกับข้ออ้างแล้ว จึงแก้นิยามให้ตัวอย่างนั้นไม่นับเป็นสมาชิก

คนไทยไม่ทำแบบนี้ · มีคนไทยทำ · งั้นคนไทยแท้ ๆ ไม่ทำแบบนี้

ทำไมถึงสับสนกัน

ทั้งคู่คือการขยับกติกาหลังเห็นผลแล้ว เพื่อให้ข้ออ้างเดิมไม่มีวันถูกหักล้าง

สองอันนี้เป็นเครื่องมือเดียวกันที่จับคนละด้าม ทั้งคู่ทำให้ข้ออ้างกลายเป็นสิ่งที่พิสูจน์ว่าผิดไม่ได้ ต่างกันที่ขยับอะไร

ย้ายเสาประตูขยับที่ หลักฐาน ข้ออ้างยังเป็นประโยคเดิมคำต่อคำ สิ่งที่เปลี่ยนคือ สิ่งที่จะนับว่าพอ

คนสกอตแท้ขยับที่ คำ หลักฐานยังเป็นชิ้นเดิม สิ่งที่เปลี่ยนคือข้ออ้างเอง เพราะคำในนั้นถูกนิยามใหม่ให้แคบลงจนกันตัวอย่างนั้นออกไป

วิธีแยกในสนามจริง ให้ดูว่าหลังการขยับ ประโยคข้ออ้างยังเหมือนเดิมหรือเปล่า

  • ประโยคเหมือนเดิม แต่คำขอเปลี่ยน → ย้ายเสาประตู
  • ประโยคถูกเติมคำว่า “แท้ ๆ” หรือ “ที่ถูกต้อง” เข้าไป → คนสกอตแท้

คำถามที่ใช้ได้กับทั้งคู่คือคำถามเดียวกัน คือถามล่วงหน้าว่า อะไรจะทำให้คุณเปลี่ยนใจ ถ้าตอบไม่ได้ ข้ออ้างนั้นก็ไม่ได้กำลังรอหลักฐานอยู่จริง

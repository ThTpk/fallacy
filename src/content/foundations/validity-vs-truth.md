นี่เป็นหน้าที่คนข้ามบ่อยที่สุด และเป็นหน้าที่ทำให้ทุกอย่างที่เหลือเข้าใจง่ายขึ้น

**สมเหตุสมผล (valid)** เป็นสมบัติของการเดิน ไม่ใช่ของเนื้อหา ข้อโต้แย้งสมเหตุสมผล
เมื่อ *ถ้า* ข้ออ้างทุกข้อเป็นจริง ข้อสรุปจะต้องเป็นจริงไปด้วยอย่างหลีกเลี่ยงไม่ได้

คำว่า "ถ้า" ตรงนั้นสำคัญมาก ความสมเหตุสมผลไม่ได้บอกเลยว่าข้ออ้างจริงหรือไม่

## ข้อโต้แย้งที่สมเหตุสมผลแต่ข้อสรุปเท็จ

```
ข้ออ้าง 1  แมวทุกตัวบินได้
ข้ออ้าง 2  สัตว์ที่บินได้ไม่ต้องกินอาหาร
ข้อสรุป    แมวไม่ต้องกินอาหาร
```

ข้อโต้แย้งนี้สมเหตุสมผลอย่างสมบูรณ์ ถ้าข้ออ้างทั้งสองจริง ข้อสรุปจะจริงแน่นอน
แต่ข้ออ้างทั้งสองเป็นเท็จ ข้อสรุปจึงเป็นเท็จ

การเดินไม่มีปัญหา จุดตั้งต้นต่างหากที่มีปัญหา

## ข้อโต้แย้งที่แย่แต่ข้อสรุปจริง

```
ข้ออ้าง   แม่ผมบอกว่าสูบบุหรี่อันตราย
ข้อสรุป   สูบบุหรี่อันตราย
```

ข้อสรุปเป็นจริงและมีหลักฐานทางการแพทย์รองรับอย่างหนักแน่น แต่เหตุผลที่ยกมา
ไม่ได้พิสูจน์อะไร ข้อสรุปจริงโดยบังเอิญเมื่อเทียบกับเหตุผลที่ให้

## สี่กรณีที่เป็นไปได้

|  | ข้ออ้างจริง | ข้ออ้างเท็จ |
|---|---|---|
| **สมเหตุสมผล** | หนักแน่น ข้อสรุปจริงแน่นอน | ข้อสรุปจริงหรือเท็จก็ได้ |
| **ไม่สมเหตุสมผล** | ข้อสรุปจริงหรือเท็จก็ได้ | ข้อสรุปจริงหรือเท็จก็ได้ |

มีช่องเดียวที่รับประกันข้อสรุปได้ คือสมเหตุสมผลและข้ออ้างจริงพร้อมกัน
เรียกว่า **หนักแน่น (sound)** ส่วนอีกสามช่อง ความจริงของข้อสรุปเป็นเรื่องที่ต้องไปตรวจเอง

## ทำไมเรื่องนี้ถึงสำคัญ

สองข้อสรุปที่ตามมาจากตารางนี้ เป็นหัวใจของการใช้เว็บนี้ให้ถูกทาง

**หนึ่ง** การที่ข้อสรุปของใครเป็นจริง ไม่ได้แปลว่าเหตุผลเขาดี คนพูดถูกด้วยเหตุผลที่แย่
ได้ตลอดเวลา

**สอง** การที่เหตุผลของใครแย่ ไม่ได้แปลว่าข้อสรุปเขาผิด ถ้าลืมข้อนี้จะตกหลุม
[ตรรกวิบัติของการจับตรรกวิบัติ](/fallacy/fallacy-fallacy) ทันที

## สมเหตุสมผลแต่ไร้ประโยชน์

มีข้อโต้แย้งประเภทหนึ่งที่สมเหตุสมผลร้อยเปอร์เซ็นต์แต่ไม่มีประโยชน์เลย

```
ข้ออ้าง   ยานี้รักษาโรคได้
ข้อสรุป   ยานี้รักษาโรคได้
```

ถ้าข้ออ้างจริง ข้อสรุปจริงแน่นอน จึงสมเหตุสมผลเต็มที่ แต่มันไม่พาใครจากจุดที่เขายืนอยู่
ไปไหนเลย นี่คือ [ตรรกวิบัติอ้างข้อสรุปเป็นเหตุ](/fallacy/begging-the-question)
และเป็นหลักฐานชัดที่สุดว่าความสมเหตุสมผลไม่ใช่เกณฑ์เดียวที่ใช้ตัดสินข้อโต้แย้ง
